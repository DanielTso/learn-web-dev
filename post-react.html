Getting Started with React: Building Modern UIs

React is a popular JavaScript library for building user interfaces. Created by Facebook, it lets you build complex, interactive UIs from small, isolated pieces of code called components. If you've learned HTML, CSS, and JavaScript, React is the natural next step toward building modern web applications.

Key Concepts for Beginners

1. What is React?

React is a declarative, component-based JavaScript library. Instead of manually manipulating the DOM like you learned in JavaScript, React lets you describe what the UI should look like, and it efficiently updates the page for you.

  • Declarative: You tell React what you want to display, not how to update the DOM step by step.
  • Component-Based: Build encapsulated components that manage their own state, then compose them into complex UIs.
  • Virtual DOM: React uses a lightweight copy of the real DOM to calculate the most efficient way to update the page, making your apps fast.

2. JSX: HTML-like Syntax in JavaScript

JSX is a syntax extension for JavaScript that looks similar to HTML. It lets you write UI structures directly in your JavaScript code, making components easier to read and write.

// JSX looks like HTML inside JavaScript
const element = <h1>Hello, world!</h1>;

// You can embed JavaScript expressions with curly braces
const name = "Alice";
const greeting = <h1>Hello, {name}!</h1>;

// JSX can include attributes like HTML
const link = <a href="https://react.dev">React Docs</a>;

// Multi-line JSX should be wrapped in parentheses
const card = (
    <div className="card">
        <h2>{name}'s Profile</h2>
        <p>Welcome to React!</p>
    </div>
);

Note: In JSX, you use className instead of class (since class is a reserved word in JavaScript).

3. Components: Building Blocks of React

Components are the heart of React. A component is a reusable piece of UI that can accept inputs (called "props") and returns JSX describing what should appear on the screen.

// Function Component (modern, recommended approach)
function Welcome(props) {
    return <h1>Hello, {props.name}!</h1>;
}

// Arrow function component
const Greeting = ({ name }) => {
    return <p>Welcome back, {name}!</p>;
};

// Using components (like custom HTML tags)
function App() {
    return (
        <div>
            <Welcome name="Alice" />
            <Welcome name="Bob" />
            <Greeting name="Charlie" />
        </div>
    );
}

4. Props: Passing Data to Components

Props (short for "properties") are how you pass data from a parent component to a child component. They are read-only — a component should never modify its own props.

// Parent passes data via props
function UserCard({ name, role, avatar }) {
    return (
        <div className="user-card">
            <img src={avatar} alt={name} />
            <h3>{name}</h3>
            <p>{role}</p>
        </div>
    );
}

// Using the component with different props
function App() {
    return (
        <div>
            <UserCard
                name="Alice"
                role="Developer"
                avatar="alice.jpg"
            />
            <UserCard
                name="Bob"
                role="Designer"
                avatar="bob.jpg"
            />
        </div>
    );
}

5. State: Making Components Interactive

State is data that changes over time within a component. When state changes, React automatically re-renders the component to reflect the new data. You manage state with the useState hook.

import { useState } from 'react';

function Counter() {
    // Declare a state variable "count" with initial value 0
    const [count, setCount] = useState(0);

    return (
        <div>
            <p>You clicked {count} times</p>
            <button onClick={() => setCount(count + 1)}>
                Click me
            </button>
        </div>
    );
}

function NameForm() {
    const [name, setName] = useState('');

    return (
        <div>
            <input
                value={name}
                onChange={(e) => setName(e.target.value)}
                placeholder="Enter your name"
            />
            <p>Hello, {name || 'stranger'}!</p>
        </div>
    );
}

6. Getting Started: Create a React App

The easiest way to start a new React project is with Vite, a fast build tool. Make sure you have Node.js installed, then run:

# Create a new React project with Vite
npm create vite@latest my-react-app -- --template react

# Navigate into the project folder
cd my-react-app

# Install dependencies
npm install

# Start the development server
npm run dev

This sets up a project with everything you need: a dev server with hot reloading, JSX support, and a production build command. Open http://localhost:5173 in your browser to see your app!
